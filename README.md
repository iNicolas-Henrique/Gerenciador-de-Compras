# Gerenciador de Compras

Aplicação desenvolvida em Python com Flet para cadastrar e organizar uma lista de compras.

Os dados são armazenados em um arquivo JSON e continuam disponíveis depois que o programa é fechado.

## Funcionalidades

- Cadastro de produtos
- Listagem dos itens
- Edição de compras
- Exclusão de itens
- Status Pendente ou Comprado
- Busca por produto
- Filtro por status
- Cálculo de subtotal
- Cálculo do valor total

## CRUD

| Operação | Função |
| :--- | :--- |
| Create | Cadastrar uma compra |
| Read | Mostrar os itens cadastrados |
| Update | Alterar os dados de uma compra |
| Delete | Excluir uma compra |

## Executar

Instale o Flet:

```bash
pip install flet
```

Execute o programa:

```bash
flet run main.py
```

O arquivo `compras.json` é criado quando o primeiro item é salvo.
